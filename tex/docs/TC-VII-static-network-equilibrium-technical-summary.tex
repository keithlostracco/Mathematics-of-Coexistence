\subsection{Model}\label{model}

The model augments the agent framework from TC-I with production: each
agent \(i \in \{1, \ldots, N\}\) has input vector
\(\mathbf{x}_i^{\mathrm{in}} \in \mathbb{R}_{\geq 0}^n\), output vector
\(\mathbf{x}_i^{\mathrm{out}} \in \mathbb{R}_{\geq 0}^n\), and a concave
production function
\(\mathbf{x}_i^{\mathrm{out}} = f_i(\mathbf{x}_i^{\mathrm{in}}, B_i, \mathbf{s}_i)\).
Every production step satisfies thermodynamic admissibility: output
energy \(\leq\) input energy minus maintenance \(\gamma_i B_i\) and
obligatory dissipation \(D_i \geq 0\). At steady state, aggregate flow
balances:
\(\sum_i x_{ij}^{\mathrm{in}} = \sum_i x_{ij}^{\mathrm{out}} + \psi_j - \delta_j R_j^*\).
The dependency matrix \(A \in \mathbb{R}_{\geq 0}^{n \times n}\) has
entry \(A_{jk}\) = units of \(j\) consumed per unit \(k\) produced. Each
agent solves a constrained optimization subject to production,
admissibility, shared flow balance, negative boundary constraints
(TC-I), and positive provision constraints.

\subsection{Results}\label{results}

\textbf{Theorem (Network Feasibility).} A positive-flow steady state
exists iff (a) \(\rho(A) < 1\), (b) the Hawkins--Simon condition holds
on \((I - A)\), and (c) \(\sum_j \psi_j \geq \sum_i D_i\).

\textbf{Theorem (Positive-Constraint Necessity).} Every supplier whose
output is essential to a downstream agent has an active provision
constraint \(x_{ij}^{\mathrm{out}} \geq \tau_{ij} > 0\) at any
sustainable equilibrium.

\textbf{Theorem (Shadow Price Decomposition).} At a network VE,
\(\partial U_i / \partial x_{ij}^{\mathrm{in}} = \lambda_j^* + \sum_{B,k} \mu_{Bk}^{(i)} \partial g_{Bk} / \partial x_{ij}^{\mathrm{in}} - \sum_\ell \pi_{i\ell}^* \partial x_{i\ell}^{\mathrm{out}} / \partial x_{ij}^{\mathrm{in}}\),
decomposing into scarcity price, boundary multiplier, and
flow-dependency price (network obligation).

\textbf{Theorem (Network-Augmented Cooperation Threshold).}
\(\delta_i^* \leq \delta^*_{\mathrm{autarkic}} - \kappa(d_{\mathrm{in},i}, d_{\mathrm{out},i}, \rho(A))\)
with \(\kappa \geq 0\), non-decreasing in both degrees, zero at
\(d_{\mathrm{in}} = d_{\mathrm{out}} = 0\).

\textbf{Proposition (Deception in Production Networks).} The critical
per-layer deception rate \(q_L^* \leq q_1^*\) with strict inequality for
\(L \geq 2\). Effective crossover:
\(q_{\mathrm{eff}}(L) = \frac{1}{2}(1 - (1-2q)^L)\). Verification
overhead compounds along the chain.
